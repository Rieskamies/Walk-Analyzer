# Walk-Analyzer
School task / Python-Streamlit

## What is it?

This is an analysis of a day walk including slow paced walking, fast paced walking and running. The experiment was done using phone sensors which were Linear Acceleration (Y component) and GPS Locator.

## How can I see it?

The results are hosted on Streamlit cloud: https://walk-analyzer-k8jsw7zsetnksueey3ikv7.streamlit.app/

or

You can run it from your CLI: streamlit run https://raw.githubusercontent.com/Rieskamies/Walk-Analyzer/refs/heads/main/main.py

or

Clone the repo and run it with: streamlit run .\main.py
